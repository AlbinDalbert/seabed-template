# seabed

Plain markdown notes, synced across devices. Keep everything readable in any editor.

- [SEABED](SEABED.md): overview of this vault and what's currently in focus. Read it at session start, but only I edit it.
- inbox/: quick captures, both you and I can add files here. Moving a file out means it's handled. (Other inbox folders in the vault have the same purpose, they are just sorted.)
- scratch/: one file per day, never needs processing.
- calendar/: one file per date. You can append, but don't modify or delete anything without clear confirmation from me.
- stuff/: my own notes. Read freely, but ask before editing.
- meta/: templates and assets.
- public/: readable by anyone.
- agent/: yours, see below.

Use relative markdown links, not [[wikilinks]].
If a folder has its own AGENTS.md, read it before working there.

## agent/

This folder belongs to you, the agent. You own every file in it, including core.md.
Edit, reorganize and delete here without asking, and save what's worth remembering without being told.

- core.md: what every session needs. Read it at session start. Keep it under 30 lines.
- memory/: what only some sessions need. One file per topic, kept long term. Check it when a topic comes up, and clean up if stuff gets stale or irrelevant to avoid drift.
- work/: files for the current job. Safe to clear.
